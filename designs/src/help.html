Help: turning a photo into a recipe file

The app never reads photos itself: a Claude.ai project turns a photo of a recipe into a file, and Import brings the file in. This page walks a new user through setting that project up once, then using it for each recipe. It's opened from Import's "New here?" link and the empty library's "How do I make recipe JSON?".

On a phone

One page in two parts: setting the project up (once), then each recipe. Steps are numbered cards, each with the one thing to do and, where the app can help, a button that does it: open Claude.ai, copy the instructions, download the files.

Wider screens

Setting up is easiest on a computer, so from tablet width the two parts sit side by side: set up on the left, each recipe on the right.

Below tablet width the phone layout (A to D) is used.

Questions for review

  1. Where it lives (A). Under the Import tab at /import/help, opened only from the two links (Import's "New here?" is always on Import, so it's easy to find again). Recommend: just the two links, no extra entry on Household.
  2. "Easiest on a computer" (A). Adding files to a Claude project is fiddly on a phone, so the setup says so up front and the wide layout puts setup first. Recommend: keep it.
  3. The three files (B). Downloaded one by one from the app, always the versions Import checks against. A single zip would be one tap but has to be unzipped before Claude will take the files. Recommend: three separate downloads.
  4. The instructions (D). Copy is the main action; the text itself is behind "Show the instructions" so the page stays short. Recommend: as shown.
  5. The example reply (B). A small mock of what Claude sends back, so a first-timer knows what "the file" looks like. Recommend: keep it.
