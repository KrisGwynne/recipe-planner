Help: turning a photo into a recipe file

The app never reads photos itself: a Claude.ai project turns a photo of a recipe into a file, and Import brings the file in. This page walks a new user through setting that project up once, then using it for each recipe. It's opened from Import's "New here?" link and the empty library's "How do I make recipe JSON?".

On a phone

One page in two parts: setting the project up (once), then each recipe. Steps are numbered cards, each with the one thing to do and, where the app can help, a button that does it: open Claude.ai, copy the instructions, download the files.

Wider screens

Setting up is easiest on a computer, so from tablet width the two parts sit side by side: set up on the left, each recipe on the right.

Below tablet width the phone layout (A to D) is used.

Decisions

Approved by Kris on 14 October 2026.

  • Where it lives (A). Under the Import tab at /import/help, opened only from the two existing links: Import's "New here?" and the empty library's "How do I make recipe JSON?". No entry on Household.
  • "Easiest on a computer" (A). The setup says so up front, and the wide layout puts setup first.
  • The three files (B). Three separate downloads, served from the app's own copies, so they're always the versions Import checks against. No zip.
  • The instructions (D). Copy is the main action; the full text is behind "Show the instructions".
  • The example reply (B). Keep the small mock of what Claude sends back.
